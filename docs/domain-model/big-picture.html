付箋の詳細

付箋を選ぶと、種類・ドメイン・つながり・コードの場所が出ます。

ピンチ（または Ctrl/⌘ + ホイール、右上のボタン）で拡大縮小できます。実線は流れ、点線はイベントがリードモデルに反映されることを表します。重ねて貼った付箋は、その下の付箋に付く外部システム・懸念などです。
